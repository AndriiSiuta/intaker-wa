# ✅ Angular Weather App Requirements

## 📌 Core Requirements
- [x] **Create an Angular application** with Angular CLI.
- [x] **Use Angular Material** (or another UI library of your choice) for styling and UI components.
- [x] **Create an input field** where users can search for a city by name.
- [x] **Integrate with the OpenWeatherMap API** ([https://openweathermap.org/api](https://openweathermap.org/api)) to fetch weather data.
- [x] **Display the current weather conditions** for the searched city:
    - [x] Temperature
    - [x] Humidity
    - [x] Weather description
- [x] **Display a 5-day weather forecast** for the searched city:
    - [x] Date
    - [x] Temperature (high & low)
    - [x] Weather description
- [x] **Implement error handling** for:
    - [x] Invalid city names
    - [x] Failed API requests
- [x] **Ensure responsive design** for both desktop and mobile devices.

## 🎯 Bonus Features (Optional)
- [x] **Cache weather data** for each searched city:
    - [x] Only fetch new data if older than **1 hour**.
- [x] **Allow users to save favorite cities**:
    - [x] Store favorites in **local storage**.
    - [x] Allow quick access to weather data for favorite cities.
- [x] **Write unit tests** for:
    - [x] Components
    - [x] Services
