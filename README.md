# WeatherApp

You don't need to be afraid of any API KEY, I have already added it in the code.
He is coded in Injection Token, so you can change it in one place. 

# [Checklist](../checklist.md) for the requirements.

## Cache Service

I have created a cache service to store the data for 1 hour.
If you want to change the time, you can change it in service.
You can add your favorite city in the list, it will be stored in the cache for 1 hour.

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`


## Running unit tests

Run `ng test` to execute some test still got failed.
